# GMarkdown Demo 能力验收清单

状态：**Demo 基础渲染能力验收通过（真机与 iOS 15 运行时除外）；项目数据适配与扩展能力尚未开始**。

本清单用于 Demo 阶段验证 GMarkdown 的实际支持能力。它已完成本轮基础能力验收；后续工作以 [ProjectAdoptionPlan.md](./ProjectAdoptionPlan.md) 为准。单纯“能够编译运行”不等于能力验收通过，也不等于已适配业务项目。

## 当前结论与边界（2026-09-24）

### 已完成：组件基础能力

在约定的模拟器范围内，A、B、C、D、E-01～E-07 的功能性验收已通过：常规 Markdown、公式、表格、代码高亮/复制、图片与长图、受限 HTML、Mermaid 源码、深色模式、Dynamic Type、iPhone 竖屏、iPad 横竖屏/分屏、异步加载、快速切换及重复进入均未发现阻塞问题。

这说明组件已具备通用 Markdown 阅读渲染能力；它**不表示**任意业务 Markdown 都能满足业务样式，也不表示已经完成现有业务工程的源码接入。

### 当前不纳入本轮结论

- 真机 Release 性能、内存和 iOS 15 实机运行；真机可用后另行验收。
- 干净 Xcode framework target 的源码接入；本轮先暂停，待项目数据兼容性和扩展能力确认后执行。
- 业务私有格式的识别、回调、专用样式和业务列表混排；这是下一阶段的实现任务，不是重复验收本清单的项目。

### 后续唯一入口

清空上下文后，从 [ProjectAdoptionPlan.md](./ProjectAdoptionPlan.md) 的“阶段 1：真实项目数据兼容性盘点”开始；不要再重复执行本清单中已经标记为通过的基础验收项，除非修改了相关渲染代码。

## 验收规则

- 每项记录测试日期、设备/模拟器、系统版本、输入样例、实际结果和截图或日志。
- `通过`：结果符合预期，且至少重复验证一次。
- `阻塞`：功能不可用、崩溃、内容丢失、布局不可读或影响核心使用路径。
- `观察`：存在轻微显示差异或已知限制，但不阻塞首发；必须记录影响范围。
- 任何阻塞项未关闭，不得冻结稳定版本。

## 当前基线

已确认的 Demo 基础能力：

- 源码文件夹接入后可以编译运行。
- 基础 Markdown 内容可以显示。
- 分块渲染和 TextView 渲染入口可以运行。
- 公式和表格支持横向滚动。
- 基础深色模式和 Dynamic Type 放大已验证。

这些结果只作为起始基线，不代表下面的完整验收项已经通过。
