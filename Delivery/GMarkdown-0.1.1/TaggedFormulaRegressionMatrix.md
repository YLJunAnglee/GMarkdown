## 验证层次与判定

| 层次 | 要检查什么 | 通过条件 |
| --- | --- | --- |
| 源数据 | 上表书籍、章节、块 ID 和 `txt` 未变 | 原文能逐字定位到导出 JSONL；样本文件不被复制、清洗或改写 |
| 解析保真 | `GMarkParser`/stringifier 在公式分隔符、`\tag`、花括号、中文和多行环境上不丢载荷 | 解析后的公式载荷与对应原文一致；非公式正文仍存在 |
| 分块生成 | `GMarkProcessor + GMarkChunkGenerator + addLaTexHandler()` 的正式路径 | 独立显示公式产生正确块边界；连续公式不会复用前一公式的内容或编号 |
| 渲染与布局 | 当前 `GMarkdownMultiView` | 公式主体和编号同时可见；宽度超出容器时可以访问右端；纵向浏览不被横向公式截获 |
| 安全降级 | 损坏/歧义输入 | 不崩溃、不吞并相邻正文/单元格、不静默伪造数学内容；可保留原文或明确失败状态 |

由于当前明确暂不做真机验证，最后一层只在可用的模拟器范围内补充；在视觉证据产生前，不能将 TAG-01–TAG-04 改列为“默认支持”。
