## F-008：表格内 `$\\begin{aligned}…$$` 的受控定界符降级（2026-09-17，通过）

- **验证结果（2026-09-17，用户运行）：**同章“核反应方程典例”在分块与 TextView 截图中均不再显示 `\\begin` 源码；人工转变、重核裂变、轻核聚变公式分别完整，表格行没有合并。两条路径通过。新增表格 AST 测试覆盖恢复后的 `aligned`、随后的单美元公式及相邻 `$...$` 公式不被吞连。`git diff --check` 通过；助手未编译、未运行 Swift 测试或 Demo。

## 保留的边界与取舍

- 完整 MathJax 包集是通用扩展加载，不仅针对 `\\ce`、`\\xlongequal`；但不在 MathJaxSwift 打包范围内的私有宏或损坏公式，仍可能显示红色未定义命令。这是后续定位信号，不改写源数据掩盖。
- MPITextKit 不支持表格中的彩色 `❌`、`✅` glyph。渲染层仅将这两个状态符号降级为 `×`、`✓`（B-009、B-010）；原始 Markdown 保持不变，未对其它 emoji 作推断性替换。
- 导出的 manifest 标明 `imageFilesIncluded: false`；无真实资源或不可达 URL 不能验收为位图加载成功，只能验收解析、布局和 `alt` 降级。
- TextView 行内公式略偏上、超宽行内公式等比缩小、标题/粗体/链接内部的双美元公式仍未系统覆盖，不能宣称全量通过。
- 当前真实书籍正文也未发现可用于验收普通 Markdown 链接或 `<u>` 下划线的样本；如需覆盖这些能力，应另获授权后增加独立、非书籍数据的诊断样本。
