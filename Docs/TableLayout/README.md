# TABLE 布局与样式基础能力

## 本步结果

- `GMarkTableLayout` 统一产出列宽、完整行高和表格内容尺寸，`NativeMarkdownTableView`、原集合视图 Cell 和 TextView 附件入口复用同一组结果，不再各自重复估算。
- 默认表格不再限制为两行；文字、Markdown 行内样式和公式均按最终列宽重新测量，行高取该行全部单元格的完整最大高度。
- 短表格在自然列宽总和小于容器时平均分配剩余空间；宽表格保留可读的自然列宽，通过内部 `UIScrollView` 横向滚动，不强行压缩内容。
- Markdown 分隔行中的左、中、右对齐已应用到整列；表头文字色、表头背景、交替行背景、边框颜色和边框宽度均来自 `TableStyle`。
- 容器宽度变化后重新解析、分配列宽并测量行高；外层所需高度包含行分隔线、外边框和上下 padding。
- 修正 `GMarkTableView` 在没有锁定行列时少算一个 gap 的滚动内容宽度；仅在内容确实溢出时启用内部滚动并显示横向指示器，短表格不拦截外层滚动手势。
