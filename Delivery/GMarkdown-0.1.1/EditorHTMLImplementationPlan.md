# 编辑器 HTML 展示实施约定

范围：数字实体、空白、`dir`、`CustomClickableSpan` 的展示及其所需的解析边界。业务自行选择输入字符串。TextView 入口统一、图片能力与新增失败通知不在本轮范围。

## 架构

- 新增显式 `GMarkHTMLProcessor.process(html:)`，直接解析编辑器 HTML，绕开 Markdown 预处理。输出沿用 `GMarkChunk` 和 `GMarkdownMultiView`；不改变第三方 `ChunkGenerator` 协议。
- HTML tokenizer 负责标签、精确属性名、引号、注释及丢弃容器；有限元素树维护匹配闭合与继承，最大嵌套深度 128。
- 共享清理器保留原有 HTMLBlock/InlineHTML 调用接口；完整 HTML 的方向和段落语义以新入口验收。MarkdownTextView 的旧行内插件不改。
- 先解码文本节点，再生成文字；解码结果不再次解释为标签。数字实体支持带分号的十进制/十六进制写法；零码点、代理区、越界用 U+FFFD，控制字符按 HTML 映射；无法识别的实体保留原文。`nbsp` 保留 U+00A0。
- 普通 ASCII 空白跨行内节点折叠；段落首尾排版空白去除，NBSP 保留。空列表项仍去除。
- `dir` 在元素作用域内继承；`auto` 从该元素的首个强方向字符决定，跳过另有方向的子元素，无强字符为 LTR。段落基准方向与行内 writingDirection embedding 属性分别生成，不承诺浏览器完整双向隔离语义。
- 自定义标记为行内标记，属性保存在最终富文本上，范围是对应 chunk 的 UTF-16 范围。嵌套标记使用外层标记；相邻标记独立。自动折行和 br 保留标记；段落边界终止未闭合行内标签。标记内普通下划线合并为一条点状虚线，颜色固定为 #4F5CE7；文字本身仍继承原有颜色。MultiView 文本块按实际行区域单独绘制虚线，位于整行文字布局框下方 2 pt，并为后续行和末行预留空间；其他入口保留原生下划线回退。
- 解析出的段落合并为适量文本块，段落本身不在 UTF-16 中间硬切。重排沿用现有文本布局。更新页面时显式刷新保留身份的条目，覆盖仅属性变化的情况。

## 验证

解码一次、非法数字、NBSP、标签间空白；属性精确匹配、注释、闭合恢复、深层输入；方向继承与 auto；中文/emoji 标记范围、相邻/嵌套/空标记、跨行；HTML 中 Markdown 字符保持原文；同标识仅改样式时刷新。使用原始文章及独立合成 HTML 样本验证分块、字号变化和虚线，保留已有未提交样本。完整第二类原文与期望截图未取得，合成样本不替代业务视觉验收。

## 实施结果（2026-09-30）

已按上述边界实现。Review 补修了空列表图片回调保留、非法标签扫描避免重复扫描、同身份样式刷新时捕获不可变身份值，以及未带 CSS 的 Markdown 行内标签保持原段距。最终 Review 扩展至 20 项 HTML 单测与 2 项 UI 测试，均通过并检查截图；具体接入方式、限制及审查结论见 `RichTxtHTMLSupportScope.md` 和 `CustomClickableSpanReview.md`。下一项工作等待用户确认。
