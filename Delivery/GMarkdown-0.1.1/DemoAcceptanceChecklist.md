# GMarkdown Demo 能力验收清单

状态：**验收进行中；核心渲染项已完成首轮验证，尚未冻结稳定版本**。

本清单用于 Demo 阶段验证 GMarkdown 的实际支持能力。接入正式项目之前，必须完成核心项并保留可复现的验收记录。单纯“能够编译运行”不等于能力验收通过。

## 验收规则

- 每项记录测试日期、设备/模拟器、系统版本、输入样例、实际结果和截图或日志。
- `通过`：结果符合预期，且至少重复验证一次。
- `阻塞`：功能不可用、崩溃、内容丢失、布局不可读或影响核心使用路径。
- `观察`：存在轻微显示差异或已知限制，但不阻塞首发；必须记录影响范围。
- 任何阻塞项未关闭，不得冻结稳定版本。

## 当前基线

已确认的 Demo 基础能力：

- 源码文件夹接入后可以编译运行。
- 基础 Markdown 内容可以显示。
- 分块渲染和 TextView 渲染入口可以运行。
- 公式和表格支持横向滚动。
- 基础深色模式和 Dynamic Type 放大已验证。

这些结果只作为起始基线，不代表下面的完整验收项已经通过。

## 2026-09-20 首轮验收记录

环境：iPhone 17 Simulator，iOS 26.3；证据为本轮验收截图和 Demo 运行结果。

本轮已验证：

- 基础 Markdown：段落、H1-H6、粗体/斜体、列表、嵌套列表、引用、分隔线、任务列表、脚注和受限 HTML。
- 链接和图片：链接可正常打开，图片资源正常加载。
- 代码：Python、JavaScript、HTML、Mermaid 源码块显示、语法高亮、横向滚动和 Copy 操作正常。
- 公式：行内公式、分数、根式、求和、积分、极限、矩阵、行列式、方程组和分段函数正常。
- 表格：简单表格、复杂表格、图片/链接单元格和横向滚动正常。
- 显示适配：Dynamic Type 放大、深色模式下的正文、代码、表格、链接、图片和公式正常。

本轮发现并已修复：

- Dynamic Type 放大后，有序列表的编号和正文会垂直分离。已改为动态字体配合首行缩进/悬挂缩进，重新构建并在大字体下复验通过。

## 2026-09-21 稳定性验收记录

环境：iPhone 17 Simulator，iOS 26.3.1。

测试范围：连续切换 `markdownv2`、`markdownLatex`、`markdownv5`，每篇快速上下滚动；返回文章列表后重复打开同一篇文章并快速滚动，重复多次。

结果：未发现旧内容串入、标题与正文不一致、布局跳动、滚动位置异常、重复渲染或崩溃。E-04、E-05 通过。

补充结果：使用 `markdownAcceptanceEmpty`、`markdownAcceptanceWhitespace`、`markdownAcceptanceLong` 和 `markdownAcceptanceUnicode` 完成空内容、仅空白、超长单段文本及特殊 Unicode/Emoji 验收。构建运行通过，查看无异常，未发生崩溃。E-01、E-02、E-03 通过。

Release 结果：Release 模拟器构建运行通过，核心 Markdown 内容、资源和滚动正常，无崩溃。控制台出现选择 Markdown 文件弹窗的 UIKit 非阻塞约束警告，但弹窗可正常显示和点击，不影响正文渲染。E-07 通过。

降级验收结果：在 iPhone 17 Simulator、iOS 27.0 上验证 `markdownAcceptanceInvalidFormula`、`markdownAcceptanceUnknownCode` 和 `markdownAcceptanceMissingImage`。非法公式保留为可读源码，未知语言代码块正常显示，缺失图片显示占位内容，前后文本均保留，三项均未崩溃。B-03、C-03、C-05 通过。

iPad 适配结果：在 iPad Air 13-inch (M4)、iPadOS 27.0 上验证竖屏、横屏和窄窗口/分屏状态。页面方向、正文布局、矩阵公式和纵向滚动正常，未发现旋转错位、大面积空白、公式永久截断或崩溃。D-04 通过。

最终复验结果：最新 Release 构建运行正常；`markdownLatex` 长公式可左右拖动查看完整内容，公式横向滚动与外层纵向滚动均正常。D-06、E-07 风险关闭。

## 稳定版本冻结条件

满足以下条件后，才能标记 Demo 为稳定基线：

1. A、B、C 的核心项全部通过；
2. D-01、D-02、D-03、D-05、D-06 全部通过；
3. E-01 至 E-07 无阻塞问题；真机项目不可用时，E-08 必须明确标记为未完成风险；
4. F-01 至 F-05 通过；
5. 所有 `阻塞` 问题已关闭，所有 `观察` 项有明确说明；
6. 保存验收输入样例、截图、构建日志和已知限制；
7. 冻结源码、资源、依赖版本和校验文件，不再直接修改稳定目录。
