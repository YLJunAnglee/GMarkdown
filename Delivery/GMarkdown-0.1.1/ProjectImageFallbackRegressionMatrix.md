# 项目图片安全降级回归矩阵

状态：模拟器断言通过（2026-09-24）。本文件只验证脱敏书籍未随包图片资源的可读降级；不把 Demo 基础图片验收或真实图片加载重复计入。

## 前提

- 9 本书的 manifest 都声明 `imageFilesIncluded: false`，因此当前数据包不能验证图片成功下载、鉴权、缓存或失效刷新。
- 正式分块路径是 `GMarkProcessor + GMarkdownMultiView`。图片由文本附件调用宿主的 `ImageLoader`；Demo 的 `NukeImageLoader` 在无效 URL 或下载失败时显示 `alt` 文本，并在图片结果变化后重新布局。
- HTML 不是 WebView：`img` 只保留安全文本信息，不执行 URL、样式或脚本。

## 本轮判定

`ProjectImageVisualTests` 已在 iPhone 17（iOS 27.0）Simulator 通过两项真实章节导航和分块渲染断言：IMG-01 的 `图8-7` 与后续正文均可访问，IMG-02 的两段 HTML 图片 `alt` 均可访问。用例请求保留 IMG-01/02 截图附件；本次 Xcode result bundle 缺少 `Info.plist`，附件无法在测试后离线读取，因此不把它作为可归档截图证据。上述结果说明未随包或语义占位图片在当前数据中可读降级；不等同图片加载成功。

## 仍需业务提供的输入

若正式产品要求显示图片，请提供至少一个可访问的脱敏图片 URL（含需要鉴权时的请求方式）、期望缓存/失效规则和失败文案。届时由宿主 `ImageLoader` 接管认证、缓存与失败显示；当前不需要项目自定义 Markdown 块或组件扩展。
